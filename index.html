faq

The questions that come up every time.

What exactly is a "skill"?

A folder of instructions (and, where needed, scripts) that teaches Claude Code how to do one specific task the same way every time — reading a Google Ads account, writing brand copy, cutting a video into a carousel. Without it, you'd have to explain the whole process again every conversation.

Do I need to know how to code?

No. You talk to Claude in plain English and it runs the skill. You do need Claude Code installed — Claude itself walks you through that the first time.

What do I need installed?

Claude Code, plus whatever a specific skill needs (a few use Python, some need a free API key from Google or Meta). Each skill tells you exactly what's missing the first time it needs something, with the install command for your OS.

Does this work on Windows or only Mac?

Both. The skills are Python and JavaScript, which run the same on Mac, Windows, and Linux.

Do I need to pay for any API separately?

Depends on the skill. Several (video-to-carousel, yt-transcript, the copy skills) need nothing beyond what's included. The ones that connect to Google Ads, GA4, or Meta use your own free developer accounts — no extra subscription from us either way.

Is this a subscription?

No. Single skills and the full stack are both one-time payments, yours to keep.

Can I use this for client work?

Yes — the license covers your own work and work delivered to your clients. What's not included is reselling the skill itself as your own product.

What if I buy one skill and want the full stack later?

Reach out and the price of what you already bought gets credited toward the bundle.
